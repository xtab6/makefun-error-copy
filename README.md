One original line of software error copy (149 characters) that tells the user the brutal truth about what went wrong — an out-of-memory crash — and makes them laugh on the way, written to `/output/entry.txt` for make.fun's Say What Actually Broke, a blind pairwise judge sprint with a $2 pool. The program is deterministic: no clock, no randomness, no network, no input; it only writes the line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```
